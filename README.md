# 时间序列异常检测可视化汇报示例（科学计算可视化）

本仓库提供一套可直接运行的 Python 示例代码，用公开数据集展示“时间序列异常检测”的可视化汇报流程，覆盖：

- 背景介绍
- 具体方法
- 用可视化展示研究难点
- 生成可用于课堂汇报的图
- 典型应用场景

---

## 1. 数据集（公开）

使用 **NAB（Numenta Anomaly Benchmark）** 公开数据集中的样例：

- 文件：`data/nab/realKnownCause/ambient_temperature_system_failure.csv`
- 标签：`data/nab/labels/combined_windows.json`

该样例是温度传感器时间序列，包含已标注异常时间窗口，适合教学演示。

---

## 2. 方法设计（用于汇报）

示例脚本 `visualize_ts_anomaly.py` 对同一数据执行两种方法并可视化对比：

1. **Robust Z-Score（基于滚动中位数 + MAD）**
   - 强调“可解释性强、实现简单”
   - 适合做传统统计基线

2. **Isolation Forest（机器学习方法）**
   - 基于多维时序特征（值、差分、滞后、局部统计）
   - 适合展示“从统计到学习方法”的升级路线

---

## 3. 可视化如何体现研究难点

脚本会输出 4 张图到 `figures/`：

1. `01_raw_with_ground_truth.png`
   - 原始序列 + 真实异常窗口（难点：异常稀疏、被趋势/噪声淹没）

2. `02_robust_zscore_detection.png`
   - 统计法检测结果 + 分数阈值图（难点：阈值敏感、误报漏报平衡）

3. `03_iforest_detection.png`
   - 机器学习法检测结果 + 分数图（难点：特征工程与污染率设定）

4. `04_method_comparison.png`
   - Precision/Recall/F1 对比 + 同图叠加预测点（难点：评价指标权衡）

---

## 4. 运行方式（直接出图）

在仓库根目录执行：

```bash
python -m pip install -r requirements.txt
python visualize_ts_anomaly.py
```

运行后会在 `figures/` 下生成全部示例图。

## 5. 10页左右汇报PPT讲稿提纲（可直接用）

### 第1页｜题目与研究背景
- 标题：时间序列异常检测中的科学计算可视化方法
- 要点：研究方向、课程目标、汇报结构（背景→方法→难点→应用）
- 讲稿：先说明“为什么要做可视化”，它不仅展示结果，更帮助理解模型行为与研究瓶颈。

### 第2页｜问题定义与应用价值
- 要点：时间序列异常检测定义；异常类型（点异常/上下文异常/集体异常）；应用场景（工业监控、运维告警、金融风控）
- 讲稿：强调异常通常“少而关键”，可视化是把稀疏信号从噪声中“看出来”的核心手段。

### 第3页｜公开数据集介绍（NAB）
- 要点：NAB数据集、选用样例 `ambient_temperature_system_failure`、带标注异常窗口
- 讲稿：说明为什么选这个数据：公开、可复现、适合课堂演示，且有真实异常时间段标签。

### 第4页｜研究流程总览（流程图页）
- 要点：数据读取→标签对齐→特征构建→两类方法检测→指标评估→图形输出
- 讲稿：给听众先建立“全流程地图”，后面每页对应流程中的一个关键节点。

### 第5页｜可视化图1：原始序列+真实异常窗口
- 要点：展示 `01_raw_with_ground_truth.png`；异常稀疏、趋势与噪声干扰明显
- 讲稿：指出第一个难点：只看原始曲线很难稳定识别异常，需要方法和可视化协同。

### 第6页｜方法A：Robust Z-Score（统计基线）
- 要点：滚动中位数+MAD思想；阈值判定；优点（简单可解释）与局限（阈值敏感）
- 讲稿：强调这是“可解释强基线”，适合先给出可理解的参照。

### 第7页｜可视化图2：Robust Z-Score检测结果
- 要点：展示 `02_robust_zscore_detection.png`；预测点与GT窗口对比；误报/漏报讨论
- 讲稿：点明第二个难点：阈值变化会显著改变召回率与精确率。

### 第8页｜方法B：Isolation Forest（学习方法）
- 要点：特征（值、差分、滞后、滚动统计）；异常分数；污染率(contamination)设定
- 讲稿：强调从“单一阈值”走向“多特征建模”，检测能力更灵活，但参数选择更复杂。

### 第9页｜可视化图3+图4：方法对比与评价指标
- 要点：展示 `03_iforest_detection.png` 与 `04_method_comparison.png`；Precision/Recall/F1权衡
- 讲稿：聚焦第三个难点：不存在单一最优指标，需根据业务代价在误报和漏报间取舍。

### 第10页｜结论、论文图补充与后续工作
- 要点：结论（可视化帮助理解数据、方法、误差来源）；可加入论文截图页（标注来源）；后续方向（深度学习/在线检测/可解释性增强）
- 讲稿：收束为“方法+可视化+应用”的统一框架，说明你的研究可继续扩展到更复杂场景。
